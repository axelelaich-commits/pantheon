# PANTHÉON — La Descente

Roguelite mobile en pixel art, fait sous Godot 4.7.

**Jouer :** https://axelelaich-commits.github.io/pantheon/

Sur iPhone, ouvre ce lien dans Safari puis Partager → « Sur l'écran d'accueil ».
Lance ensuite toujours le jeu depuis cette icône : la sauvegarde est gardée.

Ce dépôt ne contient que la version web exportée (le projet Godot reste en local).
